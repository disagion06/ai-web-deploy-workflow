DesignDeployer

一句话生成网页
自动脱敏，一键上线

「AI 生成网页」的 demo 满大街都是，但没有一个管生成结果的隐私。 AI 做出来的个人主页里，常常带着你喂给它的真实手机号、邮箱、照片 GPS。 这个工具在生成之后就接管：扫一遍、你逐项决定、改写后再自检一遍、上线后抓真实链接复核一遍。

整条流水线

01

生成网页 新增

一句话描述需求 → 区块规划 → 分块生成 → 确定性组装。AI 只产出区块片段，骨架和拼装是代码，所以单块失败只坏一块、可单独重做。

02

扫描敏感信息

21 条规则：手机号、邮箱、身份证、银行卡（含 Luhn 校验）、QQ、微信、中文姓名（能识别被标签拆开的姓名）、出生年月、详细住址、学号、密钥、学校、公司、城市、社交账号，外加图片 EXIF / GPS / 人像识别。

03

逐项选择

打码 / 删除 / 隐藏整块 / 保留，带打码效果预览与「文件:行:列」命中位置。图片是模糊 / 删除 / 保留。

04

脱敏生成并自检

文本改写、删空条目整块隐藏、图片马赛克并剥离 EXIF/GPS、摘除被排除文件的引用、写 .nojekyll，然后对生成结果再扫一遍自检。

05

上线 GitHub Pages

git init / commit → 建库 → push → 开 Pages → 轮询构建 → 强制 HTTPS → 抓真实链接复核敏感值是否消失 → 输出链接。

冒烟测试用的是运行时生成的全合成测试站（假手机号、假人像、52MB 稀疏视频、_ 目录、误报陷阱）， 不依赖任何一台机器的路径，也不含真实个人信息 —— 任何人克隆下来都能跑通。 模型适配器测试起一个本地假模型服务器，验证 429 重试、401 不重试、SSE 流式、主备降级与成本计量。

素材规整的五条硬约束

这些是手工实操时真踩过坑才发现的知识，现在固化成程序里的确定性检查。

编号约束不遵守会怎样
C1素材文件名必须 ASCII / 拼音发布后裂图
C2视频必须是 H.264HEVC 浏览器播不了（手写 MP4 box 解析探测）
C3PSD / AEP 不能直接展示需先导出预览图
C4视频要抽首帧做封面灯箱黑屏
C5图片必须写死静态 src靠 JS 注入会在发布后裂图

怎么跑起来

# 1. 装依赖（Electron 只作桌面外壳，运行时零第三方依赖）
npm install

# 2. 图形界面
npm start

# 3. 命令行一条龙：生成 → 脱敏 →（可选）上线
npm run cli -- make .work/my-site --brief "个人作品集单页，含作品列表与联系方式"

# 4. 换成真模型（不配则用内置 mock，无需任何 key 也能跑通全流程）
set DEEPSEEK_API_KEY=sk-...
npm run cli -- make .work/my-site --brief "个人作品集" --provider deepseek --model deepseek-chat
  • 图形界面第 1 步有「AI 生成网页 / 已有设计稿」两个入口，生成完可直接跳进脱敏。
  • 模型可插拔：mock / DeepSeek / 火山方舟豆包 / 通义 / Kimi / OpenAI / Claude，统一走 OpenAI 兼容格式。
  • API key 只从环境变量或用户目录配置读取，不入日志、不落仓库。
